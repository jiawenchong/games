# 盛世天下 · 女帝篇

一款純前端的中式宮廷模擬經營遊戲。先帝驟崩,你以皇長女之身登基稱帝——
執掌乾坤,天下為棋。能否在權臣、外敵、天災與人心之間,把江山坐成盛世?

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可(建議 Chrome / Edge / Safari,桌面與手機皆可)。

或啟動任一靜態伺服器:

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

無需安裝、無需構建、無外部資源依賴。

## 玩法

- **每季一項行動**:臨朝聽政、體察民情、整軍經武、清理度支、靜養休憩,行動直接影響屬性並引出對應事件。
- **五維屬性**:民心 🌾 / 威望 👑 / 國庫 💰 / 軍力 ⚔️ / 龍體 ❤️ —— 任何一項歸零即是終局。
- **事件抉擇**:40+ 張事件卡與多條劇情連鎖(攝政王之亂、北狄犯邊、國本之爭、女學興辦……),每個選擇都有代價。
- **大臣忠誠**:丞相、大將軍、戶部尚書、繡衣使——歲末時忠臣輔益其司,離心之臣拖累朝政。
- **盛極而衰**:屬性過盛(80+)則驕奢暗生,每季自耗。盛世,難在「守」字。
- **勝利條件**:在位滿 8 年且四維皆至 82,歲末達成「盛世天下 · 千古女帝」傳奇結局。共 8 種結局可收集。

## 特性

- 季初自動存檔,可隨時關閉瀏覽器續玩(localStorage)
- 結局圖鑑收集
- WebAudio 即時合成的古箏撥弦音效與背景琶音(無音訊檔案)
- 打字機文本、屬性飄字、卡牌動效
- 響應式版面,支援手機

## 技術

純 HTML / CSS / 原生 JavaScript,零依賴。

```
index.html      入口與版面
css/style.css   樣式(中式暗金主題)
js/data.js      事件卡、劇情連鎖、結局等資料
js/game.js      遊戲引擎(回合流程、存檔、結算)
js/audio.js     WebAudio 合成音效
```
